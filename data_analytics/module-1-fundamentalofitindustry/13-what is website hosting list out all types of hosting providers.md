WEBSITE HOSTING
===============

DEFINITION
----------

Website hosting is a service that stores website files on a server
and makes the website available on the Internet.

When a user enters a website URL, the hosting server sends the
website files to the user's browser.

EXAMPLE:
```

                   Website Files
                          ↓
                  Hosting Server
                          ↓
                      Internet
                          ↓
                    Web Browser
```

TYPES OF WEB HOSTING
====================

1. SHARED HOSTING
-----------------

Multiple websites share the same server resources.

Example: Suitable for `small websites` and blogs.


2. VPS HOSTING
--------------

A physical server is divided into multiple virtual servers.

Example: Suitable for `growing websites and applications`.


3. DEDICATED HOSTING
--------------------

A complete physical server is dedicated to one website or customer.

Example: Suitable for `large and high-traffic websites.`


4. CLOUD HOSTING
----------------

Websites are hosted on multiple connected cloud servers.

Example: Suitable for `scalable and high-traffic websites`.


5. WORDPRESS HOSTING
--------------------

Hosting specially optimized for WordPress websites.

Example: Suitable for `WordPress blogs and business websites`.


6. RESELLER HOSTING
-------------------

Allows a person or company to sell hosting services to customers.

Example: Web designers selling hosting to their clients.


7. MANAGED HOSTING
------------------

The hosting provider manages server maintenance, security,
updates, and technical tasks.

Example: Managed WordPress hosting.
