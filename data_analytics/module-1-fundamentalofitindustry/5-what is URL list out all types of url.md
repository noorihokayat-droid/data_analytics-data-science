# URL (Uniform Resource Locator)

## Definition

A **URL** is the address used to locate a resource on the internet.

### Example

https://www.example.com

---

# URL Structure

https://www.example.com:443/products?id=10#details

* `https://` → Protocol
* `www` → Subdomain
* `example.com` → Domain
* `:443` → Port
* `/products` → Path
* `?id=10` → Query
* `#details` → Fragment

---

# Types of URLs

## 1. Absolute URL

Complete URL with domain.

`https://example.com/about.html`

## 2. Relative URL

URL relative to the current page.

`/about.html`

## 3. HTTP / HTTPS URL

Used to access web resources.

`http://example.com`

`https://example.com`

## 4. FTP URL

Used for file transfer.

`ftp://example.com/file.zip`

## 5. File URL

Used to access local files.

`file:///C:/file.txt`

## 6. Mailto URL

Used to open an email application.

`mailto:example@email.com`

## 7. API URL

Used to access API data.

`https://api.example.com/users`

## 8. Dynamic URL

Contains changing parameters.

`https://example.com/product?id=123`

## 9. Static URL

A fixed URL.

`https://example.com/about.html`
