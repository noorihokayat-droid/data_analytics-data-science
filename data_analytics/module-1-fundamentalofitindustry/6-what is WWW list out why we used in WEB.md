# WWW (World Wide Web)

## Definition

**WWW** stands for **World Wide Web**. It is a worldwide system of interconnected web pages, websites, documents, images, videos, and other online resources.

The WWW allows users to access and share information through the Internet using web browsers.

The Web works with technologies such as **HTML, CSS, JavaScript, HTTP, HTTPS, and URLs**.

---

# Important Components of WWW

* **Web Browser** - Software used to access websites.
  * Examples: Chrome, Firefox, Edge, Safari

* **Web Server** - Stores and delivers websites and web pages.

* **Web Page** - A document displayed in a web browser.

* **Website** - A collection of related web pages.

* **URL** - The address used to locate a web resource.

* **HTTP / HTTPS** - Protocols used to transfer web data.

---

# Why Do We Use WWW?

* To access websites and web pages.
* To share information globally.
* To connect web pages using hyperlinks.
* To access text, images, audio, videos, and documents.
* To use online services such as:
  * Online shopping
  * Online banking
  * Education
  * Social media
  * Entertainment
  * Online communication
* To access websites from anywhere using the Internet.
* To connect users with web servers and online resources.

---

# Features of WWW

* **Global Access** - Information can be accessed from anywhere in the world.
* **Easy Navigation** - Hyperlinks help users move between web pages.
* **Multimedia Support** - Supports text, images, audio, video, and animations.
* **Interactive** - Users can interact with websites and online applications.
* **Searchable** - Search engines help users find information quickly.
* **Dynamic Content** - Web pages can display updated and interactive content.
* **User-Friendly** - Information can be accessed easily through web browsers.
