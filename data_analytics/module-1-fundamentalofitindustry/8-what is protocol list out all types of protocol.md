# Protocol

## Definition

A **protocol** is a set of rules that allows computers and devices to communicate and exchange data over a network.

---

# Types of Network Protocols

## 1. HTTP

Used to transfer web pages.

**Example:** `http://example.com`

---

## 2. HTTPS

A secure version of HTTP.

**Example:** `https://example.com`

---

## 3. FTP

Used to transfer files.

**Example:** Uploading files to a server.

---

## 4. SFTP

Used to securely transfer files.

**Example:** Secure server file transfer.

---

## 5. SMTP

Used to send emails.

**Example:** Sending an email.

---

## 6. POP3

Used to download emails.

**Example:** Downloading emails to a computer.

---

## 7. IMAP

Used to access and synchronize emails.

**Example:** Accessing email on a phone and laptop.

---

## 8. DNS

Converts domain names into IP addresses.

**Example:** `google.com → IP Address`

---
## 9. TCP

Provides reliable and ordered data delivery.

**Example:** Web browsing and file downloads.

---

## 10. IP

Identifies devices and routes data.

**Example:** `192.168.1.1`

---



## Simple Definition

**A protocol is a set of rules that defines how devices communicate and exchange data over a network.**
