# Case 1: Student Management System

**Tables:** `students`, `courses`, `enrollments`, `teachers`

1. Create a `students` table with `student_id`, `name`, `email`, `phone`, `dob`, and `city`.

```
    create table students
    (
        student_id int AUTO_INCREMENT primary key,
        name varchar(255),
        email varchar(255),
        phone bigint,
        dob date,
        city varchar(255)
    );
```

2. Create a `courses` table with `course_id`, `course_name`, `duration`, and `fees`.
```
    create table courses 
    (
        course_id int AUTO_INCREMENT primary key,
        course_name varchar(255),
        duration varchar(20),
        fees decimal(10,2)
    )
```
3. Create an `enrollments` table with `enrollment_id`, `student_id`, `course_id`, and `enrollment_date`.
```
    CREATE TABLE enrollments (
    enrollment_id INT AUTO_INCREMENT PRIMARY KEY,
    student_id INT,
    course_id INT,
    enrollment_date DATE,
    FOREIGN KEY (student_id) REFERENCES students(student_id),
    FOREIGN KEY (course_id) REFERENCES courses(course_id)
);

```
4. Add a `gender` column to the `students` table.
```
    alter table students add gender enum('male','female','other');
```
5. Rename the `phone` column to `mobile`.
```
   alter table students change phone mobile varchar(20);
```
