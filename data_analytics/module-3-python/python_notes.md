# type() Function and Typecasting :

- type() function is used to find the data type of a given variable in python.
```
a = 31
type(a) # class <int>
b = "31"
type(b) # class <str>
```

**typecasting:** There are many functions to convert one data type into another

```
str(31)    # integer to string conversion
int("32")  # string to integer conversion
float(32)  # integer to float conversion
```
# Input() Function :

- to get input from the user like name|age|address etc.
